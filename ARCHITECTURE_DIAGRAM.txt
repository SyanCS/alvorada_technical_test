═══════════════════════════════════════════════════════════════════════════════
                          KEY ARCHITECTURAL PRINCIPLES
═══════════════════════════════════════════════════════════════════════════════

✓ SEPARATION OF CONCERNS
  Each layer has a single, well-defined responsibility

✓ DEPENDENCY INJECTION
  All dependencies injected via Container (no tight coupling)

✓ REPOSITORY PATTERN
  Data access abstracted from business logic

✓ SERVICE LAYER
  Business logic isolated from HTTP concerns

✓ THIN CONTROLLERS
  Controllers orchestrate, don't implement business logic

✓ SOLID PRINCIPLES
  S - Single Responsibility (each class has one job)
  O - Open/Closed (extensible via interfaces)
  L - Liskov Substitution (proper interface implementation)
  I - Interface Segregation (focused contracts)
  D - Dependency Inversion (depend on abstractions)


═══════════════════════════════════════════════════════════════════════════════
                              REQUEST FLOW EXAMPLE
═══════════════════════════════════════════════════════════════════════════════

GET /api/property.php?id=1

1. API Endpoint (property.php)
   ├─ Sets headers (Content-Type, CORS)
   ├─ Handles OPTIONS preflight
   ├─ Checks HTTP method
   ├─ Gets PropertyController from Container
   └─ Calls: $controller->showJson()

2. Controller (PropertyController::showJson)
   ├─ Validates: $_GET['id'] exists and is numeric
   ├─ Calls: $propertyService->getProperty(1)
   ├─ Catches: NotFoundException, Exception
   └─ Renders: View::json(['success' => true, 'property' => ...])

3. Service (PropertyService::getProperty)
   ├─ Calls: $propertyRepository->findById(1)
   ├─ Checks: Property exists (throws NotFoundException if not)
   └─ Returns: Property model

4. Repository (PropertyRepository::findById)
   ├─ Prepares: SELECT * FROM properties WHERE id = :id
   ├─ Executes: PDO prepared statement
   ├─ Fetches: Database row
   └─ Returns: Property model (or null)

5. Database (PostgreSQL)
   ├─ Executes query
   └─ Returns row data

6. Response flows back up:
   Database → Repository → Service → Controller → View → Client
